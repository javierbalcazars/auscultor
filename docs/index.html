Solo dice lo que tú le confirmaste

Nada de respuestas inventadas ni promesas que el negocio no puede cumplir. Auscultor lee únicamente los documentos que tú escribes desde el panel.

Responde desde tus propios documentos

Horarios, tarifas, ubicación y políticas se editan como texto simple, sin tocar código, y se aplican al instante.

Tus datos permanecen bajo tu control

La configuración, la sesión y el historial se guardan localmente. Para generar respuestas, Auscultor envía a OpenAI las FAQs configuradas y el historial reciente de la consulta.

Deriva a una persona cuando corresponde

Si la consulta necesita una decisión humana, el asistente pausa y avisa al encargado en vez de improvisar una respuesta.

De la descarga al primer mensaje respondido

Una experiencia guiada para instalar y configurar el asistente sin conocimientos técnicos.

1

Descarga la aplicación

Un solo archivo AppImage para Linux. Incluye todo lo necesario: no hace falta instalar Node, Python ni ningún compilador. Solo debes darle permiso de ejecución siguiendo las instrucciones de instalación.

2

Vincula tu WhatsApp

El panel muestra un código QR. Lo escaneas desde Dispositivos vinculados en WhatsApp, igual que con WhatsApp Web.

3

Completa la información de tu negocio

Escribe tus preguntas frecuentes en el panel y el asistente empieza a responder de inmediato.

Un panel, no una terminal

Configurar el asistente, vincular WhatsApp y revisar su estado se hace todo desde una ventana de escritorio.

Sin costo de licencia y de código abierto

Auscultor nació para resolver un problema concreto: atender el WhatsApp de un pequeño emprendimiento familiar en el sur de Chile cuando nadie del equipo podía responder al instante. Se comparte tal cual, sin versión paga ni funciones bloqueadas.

El código completo está publicado bajo licencia AGPL-3.0-or-later: cualquiera puede revisarlo, modificarlo y usarlo, incluso para ofrecerlo como servicio, siempre que las modificaciones se compartan igual de abiertas.

Para responder mensajes se necesita una cuenta de OpenAI. Su API es un servicio externo y puede generar cargos según el uso y el modelo elegido.
